An entry for the [make.fun](https://make.fun) competition
[The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c):
write the single sentence that could have replaced an entire pointless meeting.

## The line

> "The decision was made in the hallway before we sat down; this meeting was just the ceremony where we pretended to make it."

## How it works

`main.ts` (Node, stdlib only) writes that one line to `/output/entry.txt`,
guarded by the competition gate: 1–200 characters, not only whitespace.

Run it with Node 22.18 or later:

```sh
node main.ts
```
